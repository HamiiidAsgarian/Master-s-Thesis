## 5. LINE SPACING & PARAGRAPH FORMATTING (فاصله خطوط و پاراگراف)

| Element                  | Specification (Ardabil)            | Word Setting                                                               |
| :----------------------- | :--------------------------------- | :------------------------------------------------------------------------- |
| **Line Spacing (Body)**  | **1 cm between lines**             | Set to **Exactly 28 pt** OR **Multiple 1.5** (approx).                     |
| **Paragraph Indent**     | **1 cm** (first line only)         | Special → First line → 1 cm.                                               |
| **Paragraph Spacing**    | One blank line between paragraphs  | Set `Before: 0 pt`, `After: 0 pt`; press Enter once between paragraphs.    |
| **Alignment (Body)**     | **Justified (تراز شده)**           | Ctrl + J (both left & right edges straight).                               |
| **Orphan/Widow Control** | Prevent single lines at top/bottom | Word: Format → Paragraph → Line & Page Breaks → Widow/Orphan control = ON. |

**Key Rules:**

- **Do NOT indent** the first paragraph immediately following a heading.
- Every body paragraph must be **fully justified**.
- Paragraphs should contain **5–10 sentences** (approx. 100–200 words) – cover one main idea per paragraph.
- Avoid excessively long paragraphs (over 250 words) or very short ones (under 30 words) except for transitional sentences.

## 6. TEXT DIRECTION & ALIGNMENT (جهت و تراز)

| Language         | Direction             | Alignment |
| :--------------- | :-------------------- | :-------- |
| **Persian Text** | Right-to-Left (RTL)   | Justified |
| **English Text** | Left-to-Right (LTR)   | Justified |
| **Mixed Text**   | Unicode BiDi controls | Justified |

**Key Rules:**

- Set the Word document's default paragraph direction to **RTL** for the main Persian thesis.
- Switch to **LTR** for English abstracts, code blocks, or large English excerpts.
- Never use Left-Align or Right-Align for body text – only **Justify**.

## 7. NUMBERING SYSTEM (شماره‌گذاری سطوح)

> **Ardabil Branch uses a HYPHEN-based system (not decimal dots).**

| Level               | Format                    | Example   | Meaning                            |
| :------------------ | :------------------------ | :-------- | :--------------------------------- |
| **Chapter**         | Single number             | `2`       | Chapter 2                          |
| **Section**         | `Chapter-Section`         | `2-4`     | Chapter 2, Section 4               |
| **Sub-section**     | `Chapter-Section-Sub`     | `2-4-3`   | Chapter 2, Sec 4, Sub-sec 3        |
| **Sub-sub-section** | `Chapter-Section-Sub-Sub` | `2-4-3-1` | Chapter 2, Sec 4, Sub 3, Sub-sub 1 |
| **Equations**       | `Chapter-Number`          | `6-8`     | 8th equation in Chapter 6          |

> **RTL Reading Note:** In the Persian document, the chapter number appears on the **right** and the section number on the **left** (e.g., visually `4-2` if written RTL, but logically it means Chapter 2, Section 4). Ensure Word's field codes render correctly.

**Implementation in Word:**

- Use Word's **Multi-level list** feature.
- Link Level 1 to `Heading 1`, Level 2 to `Heading 2`, Level 3 to `Heading 3`.
- Do **not** number below sub-sub-section (use bullets or roman letters `(الف)`, `(ب)` instead).

## 9. HEADINGS & SUBHEADINGS (عنوان‌ها)

| Level                     | Formatting Style                       | Alignment    | Example                       |
| :------------------------ | :------------------------------------- | :----------- | :---------------------------- |
| **Chapter**               | Bold, Largest font (25 Lotus / 25 TNR) | Centered     | **فصل دوم: ادبیات تحقیق**     |
| **Section (1st)**         | Bold, 14 pt                            | Left-aligned | **۲-۱- مبانی نظری**           |
| **Sub-section (2nd)**     | Bold, 12–13 pt                         | Left-aligned | **۲-۱-۱- تعریف متغیرها**      |
| **Sub-sub-section (3rd)** | Bold/Italic, 12 pt                     | Left-aligned | **_۲-۱-۱-۱- شاخص‌های کلیدی_** |

**Key Rules:**

- **No orphan headings** – a heading must have at least two lines of text after it on the same page.
- Do not use more than 3 heading levels.
- Keep headings descriptive but concise.

## 10. BOLD, ITALIC, UNDERLINE (پررنگ، کج، زیرخط)

| Element           | Usage Rule                                                                                                                 |
| :---------------- | :------------------------------------------------------------------------------------------------------------------------- |
| **Bold (پررنگ)**  | Only for: Chapter Titles, Section Headings, Sub-headings, and **Key Terms** on their very first mention. Do not overuse.   |
| _Italic (کج)_     | For: Book/Journal titles in references, foreign (non-Persian) words, variables in equations ($x$, $y$), and mild emphasis. |
| Underline (زیرخط) | **AVOID COMPLETELY.** Underlining is outdated in academic formatting. Use bold or italic instead.                          |
| **Bold + Italic** | **Never combine** both unless it is a specific sub-sub-heading as noted above.                                             |

## 11. PUNCTUATION (نشانه‌گذاری) – _Persian Text_

| Symbol  | Name               | Usage                                                      |
| :------ | :----------------- | :--------------------------------------------------------- |
| **،**   | Comma (ویرگول)     | Separates items in a list, clauses.                        |
| **.**   | Full stop (نقطه)   | Ends sentences. (Use the Persian dot, not English period). |
| **؟**   | Question mark      | Ends questions.                                            |
| **!**   | Exclamation        | Rarely used in academic text; avoid unless quoting.        |
| **؛**   | Semicolon          | Separates related independent clauses.                     |
| **:**   | Colon              | Introduces lists, explanations, or block quotes.           |
| **« »** | Guillemets (گیومه) | Used for direct quotes and titles.                         |
| **( )** | Parentheses        | Additional information, in-text citations, acronyms.       |

**Critical Rules:**

- Place a **space after** punctuation marks (، . ؟ :), not before.
- Do not use English punctuation (`,` `.` `?`) inside Persian text – they render incorrectly in RTL.
- Maintain consistent punctuation throughout.

## 12. SENTENCE STRUCTURE & LENGTH (جملات)

| Element            | Recommendation                                                                                                   |
| :----------------- | :--------------------------------------------------------------------------------------------------------------- |
| **Average length** | 15 – 25 words per sentence.                                                                                      |
| **Maximum length** | 30 – 35 words (avoid run-ons).                                                                                   |
| **Voice**          | Prefer **active voice** ("ما پیشنهاد می‌دهیم") over passive, though passive is acceptable in scientific writing. |
| **First Person**   | Acceptable in modern CS theses ("I propose", "We observe") – check with supervisor.                              |
| **Tone**           | Formal, academic, objective. No colloquialisms, no slang.                                                        |
| **Terminology**    | Use precise Computer Science terminology (MARL, Reinforcement Learning, etc.).                                   |

**Key Rule:** Vary sentence length to improve readability, but never exceed 35 words in a single sentence.

## 13. BULLET POINTS & NUMBERED LISTS (نشانه‌ها و لیست‌ها)

| List Type                | Usage                                           | Indentation            | Symbol/Format                                   |
| :----------------------- | :---------------------------------------------- | :--------------------- | :---------------------------------------------- |
| **Bulleted (Unordered)** | For items with no sequence/priority.            | 1 cm from left margin. | Use `•` (bullet) or `—` (dash) – be consistent. |
| **Numbered (Ordered)**   | For sequential steps, rankings, or hierarchies. | 1 cm from left margin. | Use `1.`, `2.` or `(۱)`, `(۲)`.                 |

**Formatting Rules:**

- Introduce lists with a colon (`:`).
- If list items are **complete sentences**, capitalize the first letter and end with a period (`.`).
- If list items are **fragments**, do not use periods.
- Maintain **parallel structure** (e.g., all verbs in the same tense).
- Do not overuse bullet points – reserve them for genuinely listing 3+ items.
- For **nested lists**, use different symbols (e.g., outer: `•`, inner: `◦`).

## 14. FORMULAS & EQUATIONS (فرمول‌ها)

| Element               | Specification                                                             |
| :-------------------- | :------------------------------------------------------------------------ |
| **Editor**            | Microsoft Word Equation Editor (or MathType).                             |
| **Font**              | Times New Roman or Cambria Math.                                          |
| **Variables**         | **Italicized** (e.g., _x_, _y_, _E_, _P_).                                |
| **Constants/Numbers** | Roman (not italic) (e.g., π, e, 1.3).                                     |
| **Display**           | Centered on a separate line for major equations.                          |
| **Numbering**         | Right-aligned, in parentheses: `(۱)`, `(۲)` (Persian) or `(1)` (English). |
| **Numbering Format**  | Chapter-based: `(۶-۸)` meaning Equation 8 in Chapter 6.                   |

**Example (Persian Document):**

```
                     E = mc²                                    (۱)
```

**In-text reference:** "همانطور که در معادله (۱) نشان داده شده است..."

**Critical Rules:**

- Define **every symbol** the first time it appears (include a parameter table if > 5 symbols).
- In Persian text, equations are written **Left-to-Right** (LTR) – ensure your equation box is LTR.
- Number **all** equations that you refer back to.

## 15. FIGURES, TABLES & CAPTIONS (تصاویر، جداول و عنوان‌ها)

| Element                    | Rule                                                                                       |
| :------------------------- | :----------------------------------------------------------------------------------------- |
| **Caption Placement**      | **Table captions** → **ABOVE** the table. <br> **Figure captions** → **BELOW** the figure. |
| **Caption Font (Farsi)**   | Lotus Bold 11 (Ardabil) / B Nazanin 11 (General).                                          |
| **Caption Font (English)** | Times New Roman 11 Bold.                                                                   |
| **Numbering Format**       | Table: `جدول ۲-۱` (Chapter 2, Table 1). <br> Figure: `شکل ۳-۴` (Chapter 3, Figure 4).      |
| **Figure Resolution**      | Minimum **300 DPI** for all images.                                                        |
| **Table Formatting**       | No vertical lines. Use **horizontal lines** only (top, bottom, and header separator).      |

**Key Rules:**

- **Reference every figure/table** in the text _before_ it appears (e.g., "همانطور که در شکل ۲-۱ مشاهده می‌شود...").
- Place figures/tables as close as possible to their first reference.
- Do not split tables across pages if avoidable. Use "Keep with next" or "Repeat header rows".
- Use Word's **Insert Caption** feature to enable automatic List of Figures/Tables.

## 16. CITATIONS & REFERENCES (ارجاع‌دهی و منابع)

### 16.1 In-Text Citation Style (Ardabil Explicit Rule)

> **Rule:** In the thesis text, instead of a number and reference row, the **first and last name** and the **year of publication** should be mentioned.

**Examples (Ardabil Standard):**

- (مردوخی، احمد، ۱۳۷۵)
- (Rahimian, Ali, 2021)

### 16.2 Alternative Styles (If Supervisor Requires)

- **APA Style:** (Author, Year) – e.g., (رحیمیان، ۱۴۰۰) or (Rahimian, 2021).
- **IEEE Style:** Numerical brackets `[1]` – common in Computer Science. _Confirm with supervisor._

### 16.3 Reference List Order

| Order      | Type                          | Sorting                             |
| :--------- | :---------------------------- | :---------------------------------- |
| **First**  | **Farsi/Persian sources**     | Alphabetical by author's last name. |
| **Second** | **Non-Farsi (English, etc.)** | Alphabetical by author's last name. |

### 16.4 Reference Format Examples

**Book (Persian):**

> نام خانوادگی نویسنده، نام. (سال). _عنوان کتاب_. ناشر.

**Book (English - APA):**

> Author, A. A. (Year). _Title of book_. Publisher.

**Journal Article (English - APA):**

> Author, A. A. (Year). Title of article. _Journal Name_, _Volume_(Issue), page numbers.

**Conference Paper (IEEE):**

> [1] A. Author and B. Author, "Title of paper," in _Proc. Conference_, Year, pp. page numbers.

**Critical Rules:**

- **Cite all sources** – every claim that is not common knowledge must be cited.
- Direct quotes must include **page numbers** and be in `« »` (Persian guillemets).
- **No plagiarism** – paraphrase properly and cite.

## 17. QUOTATIONS (نقل قول‌ها)

| Type                   | Length     | Formatting                                                                                |
| :--------------------- | :--------- | :---------------------------------------------------------------------------------------- |
| **Short quote**        | < 40 words | In-text with `« »` quotation marks. Include page number.                                  |
| **Long quote (Block)** | ≥ 40 words | Separate block. Indented **1 cm** from both sides. **Single-spaced**. No quotation marks. |

**Key Rules:**

- Do not over-quote. Use your own words wherever possible.
- Always cite the source with the page number for direct quotes.

## 19. CHAPTER-SPECIFIC CONTENT REQUIREMENTS (محتویات فصل‌ها)

| Chapter                  | Must Include                                                                                                   | Must NOT Include                                            |
| :----------------------- | :------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------- |
| **1: Introduction**      | Problem statement, Significance, Objectives (Main & Secondary), Hypotheses/Questions, Operational Definitions. | Detailed literature review, Data, Results.                  |
| **2: Literature Review** | Theoretical framework, Domestic & International studies, Conceptual models, Research gap.                      | New research, Methodology details, Results.                 |
| **3: Methodology**       | Research design, Population, Sample, Tools (validity/reliability), Procedure, Statistical/ML analysis methods. | Results, Discussion, Literature review.                     |
| **4: Data Analysis**     | **Objective** presentation of findings, Tables, Charts, Statistical outputs.                                   | **NO** interpretation, discussion, or recommendations here. |
| **5: Discussion**        | Interpretation of findings, Comparison with previous studies (Chapter 2), Limitations, Future suggestions.     | New data, New literature (only refer back).                 |
