## 📋 یادداشت برای گردآوری نهایی

با اتمام ترجمه‌ی تمام شش فصل پایان‌نامه، موارد زیر برای گردآوری نهایی در قالب یک سند Word یا LaTeX باید مورد توجه قرار گیرند:

### ۱- ساختار نهایی سند (بر اساس استاندارد IAU)

| بخش                                 | توضیح                                                                                                        |
| :---------------------------------- | :----------------------------------------------------------------------------------------------------------- |
| **صفحه‌ی عنوان فارسی**              | شامل نام دانشگاه، دانشکده، گروه آموزشی، عنوان پایان‌نامه، نام نویسنده، استاد راهنما، استاد مشاور، سال (شمسی) |
| **چکیده فارسی** (حداکثر ۳۰۰ کلمه)   | خلاصه‌ای از مسئله، روش، یافته‌ها و نتیجه‌گیری — باید به‌صورت یک پاراگراف خودکفا نوشته شود                    |
| **فهرست مطالب**                     | تولید خودکار توسط Word با استفاده از استایل‌های Heading 1، 2 و 3                                             |
| **فهرست جداول**                     | تولید خودکار توسط Word از Caption Tool                                                                       |
| **فهرست شکل‌ها**                    | تولید خودکار توسط Word از Caption Tool                                                                       |
| **فهرست اختصارات و نشانه‌ها**       | جدول دوستونی (نشانه، شرح)                                                                                    |
| **متن اصلی**                        | فصل‌های ۱ تا ۵ با شماره‌گذاری فارسی-لاتین (۱-۱، ۱-۲، ...)                                                    |
| **منابع**                           | در انتهای متن — منابع فارسی و غیرفارسی به‌صورت جداگانه و به‌ترتیب حروف الفبا                                 |
| **صفحه‌ی عنوان انگلیسی**            | یک صفحه‌ی کامل در انتهای سند با عنوان انگلیسی، نام نویسنده و اطلاعات دانشگاه به‌صورت آینه‌ای                 |
| **چکیده انگلیسی** (حداکثر ۳۰۰ کلمه) | ترجمه‌ی دقیق چکیده فارسی — باید با محتوای چکیده فارسی مطابقت داشته باشد                                      |

### ۲- هشدارهای نهایی برای ویرایش در Word

| هشدار                         | راه‌حل                                                                                                   |
| :---------------------------- | :------------------------------------------------------------------------------------------------------- |
| **نشانه‌های Markdown**        | همه‌ی `#`، `##`، `**`، `-`، `` ` `` باید حذف شوند و با استایل‌های Word جایگزین گردند.                    |
| **جهت متن (RTL)**             | اطمینان از تنظیم Right‑to‑Left در Word برای متن اصلی فارسی.                                              |
| **اعداد و ارقام**             | مطابق با تصمیم‌گیری شما — در این ترجمه از ارقام غربی (۰–۹) استفاده شده است.                              |
| **معادلات**                   | باید با استفاده از Equation Editor Word بازنویسی شوند (نه به‌صورت تصویر یا متن ساده).                    |
| **ارجاعات به شکل‌ها و جداول** | شماره‌گذاری شکل‌ها و جداول باید با ارجاعات در متن هم‌راستا باشد.                                         |
| **منابع فارسی**               | چنانچه منبعی به فارسی در این پایان‌نامه وجود دارد، باید به‌صورت جداگانه در ابتدای فهرست منابع قرار گیرد. |

### ۳- تأیید نهایی توسط استاد راهنما

موارد زیر نیاز به تأیید صریح استاد راهنما دارند:

- عنوان فارسی پایان‌نامه
- چکیده فارسی
- چکیده انگلیسی
- هر گونه اصطلاح تخصصی با ترجمه‌ی مبهم

---

**پایان ترجمه**

تمام شش فصل (مقدمه، مرور پیشینه، روش‌شناسی، تحلیل داده‌ها، بحث و نتیجه‌گیری و منابع) با موفقیت ترجمه شدند. در صورت نیاز به بازبینی، ویرایش یا تنظیمات بیشتر، در خدمت شما هستم.
