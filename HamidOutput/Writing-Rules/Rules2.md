Based on the available official guidelines for Islamic Azad University, Ardabil Branch, here is a comprehensive structural template for your Master's thesis in the Faculty of Computer Science (Software Engineering). This document compiles the mandatory rules to which you must adhere, presented as a complete template.

> **⚠️ CRITICAL NOTE:** While this is based on the university's official regulations, you **must** confirm all specific requirements with your supervisor and the **امور پایان نامه (Thesis Affairs Office)** of the Ardabil branch. University regulations can be updated, and your department may have specific preferences.

### 📄 Complete Structural Template for Master's Thesis

#### 1. Physical Specifications (مشخصات ظاهری)

| Element         | Mandatory Rule                                              | Source |
| :-------------- | :---------------------------------------------------------- | :----- |
| **Software**    | Must be typed and formatted using **Microsoft Word**.       |        |
| **Paper Size**  | **A4** (21 × 29.5 cm).                                      |        |
| **Binding**     | Hardback cover (**گالینگور**).                              |        |
| **Cover Color** | **Dark Blue** (آبی تیره), preferably plain.                 |        |
| **Cover Text**  | Must be embossed in **gold or silver** (زرکوب یا نقره‌کوب). |        |

#### 2. Front Matter (صفحات فرعی / ابتدایی) - Numbered with Persian Letters (الف، ب، ...)

This section must follow this exact sequence:

| Order | Page Content                                        | Rules                                                      |
| :---- | :-------------------------------------------------- | :--------------------------------------------------------- |
| **1** | **Blank Page (آستر بدرقه)**                         | First page after the cover.                                |
| **2** | **"بسم الله الرحمن الرحیم"**                        | Page number: **الف**                                       |
| **3** | **Title Page (reprint of cover)**                   | Page number: **ب**                                         |
| **4** | **English Title Page**                              | Page number: **ج**                                         |
| **5** | **Acknowledgments (سپاسگزاری)**                     | Maximum 1 page. Page number: **د**                         |
| **6** | **Dedication (تقدیم به)**                           | Maximum 1 page. Page number: **ﻫ**                         |
| **7** | **Table of Contents (فهرست مطالب)**                 | Includes all chapters, sections, abstract, and references. |
| **8** | **List of Tables (فهرست جداول)**                    |                                                            |
| **9** | **List of Figures/Charts (فهرست نمودارها و اشكال)** |                                                            |

#### 3. Body Text (صفحات اصلي) - Numbered with Persian Numbers (1, 2, ...)

The main text must follow these formatting rules:

| Element             | Mandatory Rule                                                              |
| :------------------ | :-------------------------------------------------------------------------- |
| **First Page**      | **Persian Abstract (چکیده)** - Maximum 2 pages.                             |
| **Page Numbering**  | Persian numerals (۱، ۲، ...), centered, 1.5 cm from the bottom of the page. |
| **Margins**         | Right: 3 cm, Left: 2 cm, Top: 3 cm, Bottom: 3 cm.                           |
| **Line Length**     | 16 cm.                                                                      |
| **Line Spacing**    | 1 cm.                                                                       |
| **Font**            | **Lotus** (لوتوس) 14 pt, thin (نازك).                                       |
| **Lines per Page**  | Minimum 22, maximum 27.                                                     |
| **Borders/Headers** | No borders or headers.                                                      |

##### 3.1. Thesis Chapters (فصول پایان نامه)

The main body of the thesis is structured into the following five chapters:

1.  **Chapter 1: Introduction and Generalities (کلیات تحقیق)**
2.  **Chapter 2: Literature Review and Background (ادبیات و پیشینه تحقیق)**
3.  **Chapter 3: Research Methodology (روش‌شناسی تحقیق)**
4.  **Chapter 4: Data Analysis and Findings (تجزیه و تحلیل داده‌ها)**
5.  **Chapter 5: Conclusion and Suggestions (نتیجه‌گیری و پیشنهادات)**

#### 4. Back Matter (بخش‌های پایانی)

This section must follow this exact sequence:

| Order | Content                              | Rules                                                                              |
| :---- | :----------------------------------- | :--------------------------------------------------------------------------------- |
| **1** | **Appendices (پیوست‌ها)**            | Named with Persian letters (پیوست الف، پیوست ب، ...)                               |
| **2** | **References (فهرست منابع)**         | Persian sources first, then non-Persian sources.                                   |
| **3** | **Index (فهرست نام‌ها)**             | Optional.                                                                          |
| **4** | **English Abstract (خلاصه انگلیسی)** | Maximum 2 pages. Must include thesis title, student name, supervisor, and advisor. |

### 📝 Sectioning and Formatting Rules

#### Chapter and Section Numbering

- **Format:** `Chapter Number - Section Number - Subsection Number`
- **Example:** The third subsection of the fourth section in Chapter 2 is numbered `2-4-3`.
- **Limit:** Maximum of 4 digits. After that, use Persian letters or a dash (`-`).

#### Figures, Tables, and Equations

- **Figures/Tables:** Numbered as `Chapter Number - Sequence Number`.
  - **Example:** The 10th figure in Chapter 3 is labeled `(شکل 3-10)`.
- **Equations:** Numbered as `(Chapter Number - Equation Number)`.
  - **Example:** The 4th equation in Chapter 3 is labeled `(3-4)`.

#### In-Text Citations

- **Format:** Use the **Author's Last Name and Year of Publication**.
  - **Example:** (مردوخی، احمد، 1375)

#### References List

- **Order:** Sorted alphabetically by the Persian alphabet.
- **Language:** Persian sources first, followed by non-Persian sources.
- **Format:** The citation details must be written consecutively, separated by commas, in this order:
  1.  Number/Row
  2.  Author's Last Name
  3.  Author's First Name
  4.  Year of Publication
  5.  Title (Book, Article, Report, etc.)
  6.  Publisher, Journal, Seminar, or University Name
  7.  Page Numbers
  8.  Full Web Address (if applicable)

### ✅ Absolute MUST Rules Checklist

- [ ] **Physical Format:** A4 paper, dark blue hardback cover with gold/silver embossing.
- [ ] **Software:** Typed in Microsoft Word.
- [ ] **Font:** Lotus 14 pt for the main text.
- [ ] **Margins:** Right 3 cm, Left 2 cm, Top 3 cm, Bottom 3 cm.
- [ ] **Spacing:** Line spacing of 1 cm, lines per page between 22 and 27.
- [ ] **Page Numbers:** Front matter numbered with Persian letters (الف، ب، ...); body text numbered with Persian numerals (۱، ۲، ...).
- [ ] **Front Matter Order:** Must follow the exact sequence (Blank, Basmala, Title Page, English Title, Acknowledgments, Dedication, Table of Contents, Lists).
- [ ] **Body Order:** Persian Abstract (max 2 pages) → 5 Chapters → Appendices → References → English Abstract (max 2 pages).
- [ ] **Citations:** In-text citations must use the Author-Year format.
- [ ] **References:** Sorted alphabetically, Persian sources first.
- [ ] **Post-Defense:** Submit 4 bound copies and 2 CDs of the final thesis to the Thesis Affairs Office.
- [ ] **Article Requirement:** Provide proof of article publication/acceptance or a confirmation form from your supervisor.
