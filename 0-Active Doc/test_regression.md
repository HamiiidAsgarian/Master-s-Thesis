# فصل ۱: آزمون ریاضیات

## ۱-۱ فرمول‌های ساده

این پاراگراف شامل $x^2 + y^2 = z^2$ به‌عنوان فرمول درون‌خطی است.

فرمول با اندیس: $\bar{C}_i$ و $\text{demand met}_i$ و $\text{demand}_i$.

$$F = \frac{\left(\sum_{i=1}^{N} \bar{C}_i\right)^2}{N \cdot \sum_{i=1}^{N} \bar{C}_i^2} \qquad \text{(معادله ۱)}$$
